# myCello

myCello is my personal collection of small apps designed to be used directly on my cell phone.

Each app is something I have developed for my own daily use. The goal is simple: each app should have an easy web address that I can open from my phone and add to my Home screen like a regular app.

## Apps

- Mandarin 200 — daily practice for learning and writing 200 useful Mandarin Chinese characters.
- Radicals 60 — planned app for learning the 60 most useful Chinese radicals and common vocabulary built with them.

More private-use cell-phone apps can be added here over time.
