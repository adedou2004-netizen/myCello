# Product and MVP

myCello Mandarin is a personal, mobile-friendly learning app. The approved administration mockups use the myLexiGo wordmark. Preserve this visual distinction until a brand decision changes it.

The immediate deliverable is a local Admin Studio for the existing vocabulary: search, bulk import, edit, research, connect images, make lessons, prepare complete vocabulary card drafts, and export/restore data. It works without dictionary or AI API calls. The learning app retains its working capture, lessons, quizzes and review functions.

The studio assembles cards from verified educational data and an imported illustration. It does not include a local generative image model. A generated or saved image is a Draft until explicitly approved. Private data remains local; publication and cloud synchronization require a separate implementation.

Example sentences are optional for this application MVP. Full teaching lessons can still include example sentences. Vocabulary cards and Memory Palaces are separate concepts.
